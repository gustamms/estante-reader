# Junrar / UnRAR notice

The CBR reader uses Junrar to read RAR archives. Junrar source and binary distributions are covered by the UnRAR license, which permits use in software that handles RAR archives, free of charge. It prohibits using the code to recreate the RAR compression algorithm. Estante uses the library only to read archives.

The license is source-available and is not an OSI-approved open-source license. Keep this notice with any distribution that bundles Junrar, and review the license fit before describing an Estante release as fully open source.
